Who we are

Seven Lanterns is a small independent music label running the YouTube channels listed on our homepage. Contact: sevenlanternsmusic@gmail.com.

This website

This website uses no cookies, no analytics and no tracking, and collects no personal data.

Seven Lanterns Stats (Google / YouTube data)

Seven Lanterns Stats is an internal tool used only by the Seven Lanterns team to view statistics of our own YouTube channels. It is not available to the public.

What it accesses. With the read-only permissions youtube.readonly and yt-analytics.readonly, it reads: the channel's name and ID, subscriber, view and video counts, the list of uploaded videos with their titles, status and view/like counts, and aggregate YouTube Analytics reports (views, watch time, subscribers gained and lost). It cannot upload, edit or delete anything.

How it is used. The data is used only to draw a progress dashboard for the channel owner. It is not used for advertising, not sold, not shared with anyone, and not used to train AI or machine-learning models.

Where it is stored. Only on the team's own computer: a sign-in token per channel, and the generated dashboard page. Nothing is sent to any server other than Google's own APIs.

Deleting it. You can revoke access at any time at myaccount.google.com/permissions or via Google security settings; locally stored tokens and dashboard files are deleted on request or when the tool is no longer used.

Seven Lanterns Stats' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
